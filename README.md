### Обо мне
Учусь на 3 курсе Политеха по направлению «Прикладная математика и информатика» (профиль — биоинформатика). Мне нравится, когда код встречается с дизайном: верстаю макеты из Figma, пишу на JavaScript и собираю собственные проекты.
